
# Customer Segmentation Using Clustering

## Project Overview
This project uses Machine Learning
to divide customers into different
groups based on their income and
spending score.

## Algorithm
K-Means Clustering

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Mall Customer Segmentation Dataset.

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Scaling
4. K-Means Clustering
5. Data Visualization

## Result
Customers are divided into five
different groups based on their
purchasing behaviour.

## How to Run
pip install -r requirements.txt

python customer_segmentation.py
